# 🦢 Дворовая геральдика — интерактивный сайт

Готовый одностраничный сайт для GitHub Pages. Посетитель:
1. вводит имя/псевдоним;
2. соединяет портреты друзей и лебедей;
3. нажимает «Предъявить вердикт»;
4. результат отправляется в Google Таблицу через Google Apps Script.

## 1. Как заменить картинки

Положите свои фотографии в:

- `assets/friends/friend-01.jpg` ... `friend-06.jpg`
- `assets/swans/swan-01.jpg` ... `swan-06.jpg`

Количество участников и лебедей можно изменить в начале `app.js`.

Если нужно изменить подписи, там же замените `name`.

## 2. Как включить сбор статистики

Самый простой бесплатный вариант — Google Таблица + Google Apps Script.

1. Создайте новую Google Таблицу.
2. Откройте **Расширения → Apps Script**.
3. Скопируйте туда содержимое `google-apps-script.gs`.
4. Нажмите **Развернуть → Новое развёртывание**.
5. Тип: **Веб-приложение**.
6. «Выполнять от имени»: **Я**.
7. «Кто имеет доступ»: **Все**.
8. Скопируйте URL веб-приложения.
9. Откройте `config.js` и замените:
   `PASTE_YOUR_GOOGLE_APPS_SCRIPT_URL_HERE`
   на ваш URL.
10. Загрузите изменения на GitHub.

Результаты будут появляться на листе **Ответы**.

## 3. Как выложить на GitHub Pages

Создайте новый репозиторий на GitHub и загрузите все файлы и папки из проекта.

Затем:
**Settings → Pages → Deploy from a branch → main → / (root) → Save.**

Через некоторое время GitHub выдаст адрес сайта.

## Важно про статистику

GitHub Pages — это статический хостинг. Сам GitHub Pages не умеет принимать и хранить результаты голосования. Поэтому здесь используется Google Apps Script как маленький бесплатный сервер.

В таблице каждая строка = один участник исследования, а пары «друг → лебедь» идут отдельными колонками.

## Изменить количество карточек

В `app.js`:
- добавьте/удалите объекты в `friends`;
- добавьте/удалите объекты в `swans`.

Если хотите разрешить нескольким друзьям выбирать одного и того же лебедя, в `config.js` поставьте:

`ONE_TO_ONE: false`

По умолчанию включён режим «один друг — один лебедь».
