# Drag & Drop

Механика реализована через Pointer Events, а не через старый HTML5 drag-and-drop.

Работает:
- мышью на ПК;
- пальцем на iPhone/Android;
- стилусом.

Перетащите карточку друга на карточку лебедя. Целевая карточка подсвечивается «ОТПУСТИТЕ ЗДЕСЬ».
После соединения на обеих карточках появляется имя пары. Чтобы изменить связь, просто перетащите карточку ещё раз.
Клик по карточкам также оставлен как запасной вариант.
